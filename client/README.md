# Aara Client (React + Vite)

Frontend web application for **Aara Web Player**, built with React 18, Vite, React Router, and HTML5 Audio.

## Commands

- `npm run dev`: Launch development server on port 3000
- `npm run build`: Build production assets to `dist/`
- `npm run lint`: Run Oxlint across the codebase
- `npm run preview`: Preview production build
